## 三、GLM-5.3 能力画像（本实验最有价值的发现之一）

| 能力维度 | 套件成绩 | 相对官方模型 |
|---|---|---|
| **物体操作** | 100% / 85% | 持平最优；goal/object 四套件中三套压过 GPT-5.5 |
| **语义目标理解** | 80% / 75% | **双双压过 GPT-5.5（75/66）与 Qwen3.6（68/68）** |
| **空间关系推理** | 55% / 50% | **唯一低于所有官方模型的维度**（官方最低 69） |
| **长视野规划** | 40% / 35% | 低于官方但同量级；失败多为苦战超时（单集 38-42 分钟） |

失败有清晰的结构性：**任务级聚类失败**（特定任务两种子全败，如 spatial 系的 t1-t3/t7）而非随机失手——是能力缺口不是运气。苦战前兆可观测：上下文冲高（>150k）+ 生成量 3 倍 + 请求数 2.5 倍的重试循环，可做在线早停信号。

**选型口诀：抓放与语义任务放心用 GLM-5.3；空间布局任务需补偿手段（空间锚点记忆/人工校准）；长任务给足超时预算。**

## 四、性能画像（瓶颈是大脑，不是算力）

逐步骤耗时分解（2400+ 步全量数据）：

| 环节 | 占单集墙钟 | 实测 |
|---|---|---|
| **GLM-5.3 推理** | **85%** | 响应中位 18s / P90 39s，TPOT ≈ 22ms/tok（34-66 tok/s），TTFT 固定 8-12s |
| π0.5 VLA（NPU） | 3% | 5.6s/action-chunk（GPU 参考值慢 ~10 倍但完全够用）；pi0_pick 整技能 ≈ 67s |
| SAM3 分割（NPU） | 1% | 1-2s/次 |
| move 原语 + 仿真 | 12% | osmesa 软渲染（CPU）无压力 |

成本结构：单请求上下文中位 57k（峰值 223k）tokens，**prompt cache 命中 90.4%** 把每集 prefill 从 1.6M 压到 157k（**10 倍**）——这是长上下文 agent 可商用的前提。全战役 160 集 GLM 累计约 2.3 亿 input tokens（九成走缓存）。

**结论：这类系统对算力要求极低（NPU 只用了一张卡 20% 的显存、3% 的时间），对大脑 API 的质量、速度与价格高度敏感。国产化路径的瓶颈在模型服务，不在芯片。**

## 五、工程贡献（同环境复现的最大价值）

**NPU 三大死锁全解**（py-spy 定位，全部运行时补丁、模型权重零改动）：
1. SAM3 静默挂死 = CUDA 专用融合核 `aten._addmm_activation` 昇腾不支持 → 换通用 F.linear 路径
2. π0.5 首推理挂死 = CANN 算子编译 multiprocessing fork 死锁 → `TE_PARALLEL_COMPILER=1`
3. 长跑偶发再挂 → VLA/SAM3 外部常驻服务化（连续 ~70 小时无重启，跨集复用省 169s/集加载）

**网络方案**（华为云 HK 出口对主流 CDN 几乎全断）：7.5G 权重"Mac 经 VPN 下载 + 28 分块×6 路并行 scp"（单流 38KB/s，并行 1.2MB/s）；pip 走 aliyun、GitHub 走 gh-proxy 全局重写、SAM3 走 modelscope。

全部补丁与脚本在本仓库 `scripts/`（README 有 8 步复现流程），同事可从零复刻。

## 六、诚实声明

1. **样本口径**：20 集/套件 vs 官方 100 集；65.0% 的置信区间约 ±4 个点（65±4 跨越 ASPIRE 与 Qwen3.6 之间，第 6 名稳固）
2. **过程修正**：早前实时战报曾因宽松 grep 误计虚高（如 10_task 曾报 60%，终版 40%）；终版为双判据逐集复核结果，复核脚本可重跑
3. **一集误杀**：10_swap t9_s0 因时区误判被操作员中断，计失败（该套件 35%，此集影响 ±5 个点内）
4. **未测项**：Flash Mode、探索记忆闭环、真机迁移、官方 100 集完整口径

## 七、结论

1. **RPent 的核心主张成立且可国产化**：冻结 VLA + agent 编排 = 6 倍提升，GLM-5.3 大脑 + 昇腾算力即可落地
2. **GLM-5.3 是具身智能体的可用大脑**：总榜第 6，语义与操作维度强于 GPT-5.5，空间推理是明确短板
3. **"大脑在云端、算力在本地"是当前最务实的具身架构**：NPU 推理门槛已解决（本仓库全部补丁），瓶颈与成本都在大脑 API
4. **可复现性**：本仓库 = 报告 + 视频 + 数据 + 脚本 + 补丁全量，8 步可复刻
