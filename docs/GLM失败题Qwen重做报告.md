# GLM 失败题 Qwen3.8-Max 重做报告（换脑对照实验）

> 实验：把 GLM-5.3 在官方 8 套件战役中失败的全部 56 集，交给 Qwen3.8-Max 在**完全相同条件**下重做（同 π0.5/SAM3/记忆/100 回合预算/官方谓词判定），唯一变量是大脑。
> 执行：2026-09-26 ~ 09-28，历时约 2 天（含一次 VPN 断连期间无人值守续跑）。
> Qwen 接入：火山网关 OpenAI 兼容口 `openai-chat:Qwen3.8-Max`（本仓 155 配置），零改动。前置验证：连通 ✅ 工具调用 ✅ 视力 ✅（GLM 答错的纯红图 Qwen 答对）。

## 一、终版结果

**救回 31/56（55%）**；扣除 6 个 env 崩溃死题（LIBERO-PRO ZeroDivisionError，任何大脑都是 0 分，Qwen 重做中原样复崩验证），**可救题救回率 31/50 = 62%**。

## 二、四个核心发现

### 1. GLM 失败的一半以上是"非能力死因"，换脑即活
spatial 系救回 13/19（扣除死题后 13/15=87%）：**坐实 GLM 的"空间短板"大头是 API 502 抖动伪装的**——其可救题里 Qwen 几乎全救。object/goal 系的 API 死题也 100% 复活。

### 2. 长视野（10 系）是两个大脑共同的墙
10 系救回仅 10/25（40%）——即使看得见图的 Qwen，在微波炉三段式这类任务上同样大量回合耗尽。**证明该维度的瓶颈是范式级的（回合预算 × 技能效率），不是单一模型的能力缺口。**

### 3. 反事实双脑成绩：135/160 = 84.4%，超过 Opus-4.7
"GLM 先跑、失败题 Qwen 重试"的互补策略可得 135/160（84.4%）——**超过 Opus-4.7（82.4%）、逼近 Astra（92.63%）**，成本仅为两次 API 调用切换。两个国产大脑的失败集几乎不正交于同一原因（GLM 输在 API+空间苦战，Qwen 输在长视野），互补性极强。

### 4. 视力的价值被定量证实
Qwen（视力正常）vs GLM（工具结果通道实际失明）在同失败题上的对照：spatial 可救题 87% vs GLM 的 0%——**"让大脑看见"在空间维度价值巨大**；而 object/goal 维度 GLM 靠坐标盲跑也不输，说明语义/操作类任务对视觉不敏感。修复 GLM 视觉通道（换官方 SDK 路径）是最高性价比的上行实验。

## 三、诚实声明

1. 过程中的中期战报（"34/38 题救回"）使用了宽松 grep 判据（记忆文件引用行误计为成功），**终版 31/56 为 `I [agent] recipe` 严格判据 + finish=success 双核验结果**，与全战役终版口径一致
2. Qwen 重做批与 GLM 原战役之间隔了 1-2 天，API 服务状态不同期，"API 故障类"的死题在重做时天然占便宜（服务已恢复）
3. 6 个 env 崩溃死题（10_task t2×2、spatial_task t3/t7×4）对 Qwen 原样复崩，已从"可救题"中剔除

## 四、结论

> **换脑实验给出了全战役最后一块拼图：GLM 的 65% 里约有 12 个点是"环境/服务抖动税"，约 19 个点是"长视野范式税"，真正属于"能力差距"的损失比表面看起来小得多。双脑互补（GLM 主跑 + Qwen 重试）即可把国产全栈推到 84.4%——超过 Claude Opus-4.7。**
